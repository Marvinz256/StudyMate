# StudyMate

StudyMate is a Flutter-based learning platform for health science students. It includes premium AI learning support, clinical tools, exam prep, and professional content creation features.

## Features
- Secure authentication with Firebase
- Personalized onboarding and home experience
- AI study assistant mode and clinical ward mode
- Library, content generation, and premium subscription flows
- Modular Riverpod architecture for scalability

## Getting Started
1. Install Flutter SDK.
2. Run `flutter pub get`.
3. Configure Firebase for your platform.
4. Run the app with `flutter run`.
